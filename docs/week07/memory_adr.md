## 記憶分層、適用原因與前後差異

分類依據：`Lecture07_Agentic_AI_Engineering_Agent_Memory_Architectures.pdf` 實際頁序 6–12。投影片以 CoALA 區分記憶內容角色，另以短期／長期描述保留多久，以 context 描述本輪模型實際看見什麼。以下是本專題的對應說明，不表示安裝了 CoALA 框架或完整實作所有記憶模式。

### 依內容角色分類：CoALA 四類記憶

| PPT 類型 | 投影片意義 | 本專題對應與適用原因 | 實作界線 |
| --- | --- | --- | --- |
| 工作記憶 Working Memory | 本輪正在使用的輸入、目標、已載入資訊與工具結果；通常由 context window 承載 | 模型實際收到的當前需求、官方教師工具結果、登入問答的本人個人事實快照、Email 生成選用段落，以及 AI 調整的來源稿／本次指示；支援眼前判斷 | 後端上一位教師、草稿及 UI 狀態是組裝本輪資訊的來源；只有實際傳入該次模型呼叫的部分才算模型本輪工作資訊。程式持有資料不表示模型已看見 |
| 事件記憶 Episodic Memory | 帶有時間與情境的過去互動、觀察或行動結果，可回答哪一次發生什麼 | Sandbox outbox／receipt 含時間、request ID 與工具結果，是既有行動事件資料；支援查執行狀態與避免重複操作 | 本週未建立 Agent 的跨任務事件檢索／事件問答；不能把有 log 或 receipt 說成已完成 B 路線。個人值被覆蓋後也沒有完整事件沿革可供追問 |
| 語意記憶 Semantic Memory | 可重用的事實、使用者資訊、知識與偏好，須保留確認與更新方式 | 本人確認的「微積分→任課教師」及自介等資訊屬個人語意內容；固定文字與完整草稿是持久保存的可重用內容物。跨對話可讀回、更正及撤回，解決重複輸入 | 保存內容不代表每輪自動使用；草稿先是內容物，並非事件歷史或寫作步驟。個人關係不是官方任課證明，不能取代教師來源查核；語意記憶也不等於向量資料庫 |
| 程序記憶 Procedural Memory | 完成任務的方法、規則與技能；投影片範圍包含 LLM 能力與 Agent Code，技能檔是其中一種形式 | 原有程式與提示規則：查官方教師→驗證參數→回填模型→產生／檢查草稿→人工確認→Sandbox；本週延伸記憶 Gate 與失敗停止規則 | 主要是既有 Agent Code 的程序角色，不宣稱新增會自我學習的技能庫／SKILL 檢索、從經驗歸納流程或修改模型權重。信件正文不是程序，只描述「怎麼做」的規則才是程序內容 |

本週 A 路線的核心增量是確認後可跨任務讀回的個人事實與可重用內容；工作資訊由受控讀取後組裝。保留事件資料與程序規則不等於同時選了 B／D 或多條課程驗收路線。

### 依保存期間與本輪可見性分類

| 保存期間 | 本輪已傳入模型 context | 應用有保存，但尚未傳入該次模型 |
| --- | --- | --- |
| 短期／本次任務 | 本次訊息、已回填的工具結果、當次 AI 調整指示；模型只可使用實際收到的資料 | UI 未確認修改、仍在管理介面的內容、尚未帶入某次模型呼叫的草稿／候選；屬應用任務暫存，不自動等同模型工作記憶 |
| 長期／跨任務持久保存 | 登入問答傳給語意規劃器的本人個人事實快照；Email 初次生成選用的已存段落；AI 調整實際載入的來源內容 | SQLite 中未選取的 Email 段落或未引用完整草稿；尚未檢索回填的官方知識。已保存不代表已進入本輪或已正確使用 |

依投影片第 12 頁，**對話、RAG、checkpoint、長期記憶各有不同責任**。本專題的 UI／程序記憶體暫存可在同頁面關閉後續編，但沒有持久 checkpoint 恢復機制，不能宣稱重新整理或程序重啟後能接續未完成流程。官方快照是 RAG 的共同知識來源，與本人私有長期記憶分別管理；帳號憑證只作認證，不進模型 context。

長期記憶以 account_id／memory_id／kind／title／content／version 管理；同帳號同個人項目唯一，覆蓋檢查顯示時的版本。每帳號最多 100 筆；常用文字／手動個人記憶最多 2000 字，完整草稿正文 4000 字，模型候選值最多 200 字。SQLite 刪除不宣稱安全抹除磁碟舊頁或備份。

## 模型、一般程式與原業務的責任

- Gemini 依自然語意決定 remember／recall／campus_query／none／clarify，只提出方案。只取得當前訊息與本人個人事實快照，不取得帳密、Cookie、CSRF 或私人 Email 範本。
- Host 驗證 schema、本人 ID、原文引據、版本、官方教師與確認；執行後端受控讀寫，模型完成後重驗記憶及 session。
- 常用 Email 文字只依使用者本次選取進入生成；直接重用草稿不呼叫模型。AI 調整只用 canonical 原稿及本次指示，不自動覆寫保存模板。
- 寄信仍是獨立的人工確認與 Sandbox Write Tool；保存個人資訊或另存草稿都不是寄送授權。完成終點是 `simulated_sent` receipt，真實寄信為 0。

| 操作 | 可觀察呼叫邊界 | 尚未量測 |
